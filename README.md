# AUOLA — نظام إدارة المبيعات والأقساط

نظام متكامل لإدارة محل بيع أجهزة وإكسسوارات: أجهزة، إكسسوارات، أقساط، ديون، أرباح ومصاريف.

جميع الأجهزة (وندوز، أندرويد، آيفون) تتصل بسيرفر مركزي واحد يعمل على جهاز واحد بالمحل (عادة جهاز الوندوز)، وتشوف نفس البيانات لحظياً بدون إنترنت — يكفي أن تكون كل الأجهزة على نفس شبكة الواي فاي.

## بنية المشروع

- **`server/`** — السيرفر المركزي (Node.js + Express + Socket.IO). يخزن كل البيانات ويبثها لحظياً لكل الأجهزة المتصلة. هو أيضاً يخدم واجهة الويب المستخدمة من المتصفح والآيفون.
- **`electron/`** — تطبيق سطح المكتب لوندوز (يشغّل السيرفر تلقائياً + يعرض الواجهة بنافذة تطبيق).
- **`mobile/`** — مشروع تطبيق أندرويد (Capacitor)، يتصل بالسيرفر عبر عنوان الشبكة.
- **`.github/workflows/build-apps.yml`** — بناء تلقائي بالسحابة (GitHub Actions) لملف وندوز (exe) وتطبيق أندرويد (apk) عند كل رفع كود، متوفرين للتنزيل من تبويب Actions بالريبو.

## طريقة التشغيل

### 1) تشغيل السيرفر يدوياً (لأي جهاز)
```bash
cd server
npm install
npm start
```
يفتح على `http://localhost:4000`. لفتحه من جهاز آخر بنفس الشبكة استخدم عنوان الشبكة المحلية (IP) للجهاز، تجده بالضغط على "عرض رمز الدخول السريع" بشاشة تسجيل الدخول.

بيانات الدخول الافتراضية: `admin` / `1234` (تكدر تغيرها من صفحة الإعدادات).

### 2) تطبيق الوندوز
```bash
cd server && npm install
cd ../electron && npm install
npm run dist:win
```
الناتج بمجلد `electron/dist/*.exe` — ملف واحد يشغل نفسه، لا يحتاج تثبيت.

### 3) تطبيق الأندرويد
أسهل طريقة: تبويب **Actions** بالريبو على GitHub، آخر تشغيل ناجح، حمّل `AUOLA-Android` من قسم Artifacts.

للبناء يدوياً (يحتاج Android Studio):
```bash
cd server && npm install
cd ../mobile && npm install
cp -r ../server/public/* www/
npx cap sync android
cd android && ./gradlew assembleDebug
```
الناتج: `mobile/android/app/build/outputs/apk/debug/app-debug.apk`.

عند فتح التطبيق أول مرة، يطلب منك إدخال عنوان سيرفر المحل (تجده بشاشة تسجيل الدخول بجهاز الوندوز).

### 4) الآيفون
لا يحتاج تثبيت — يفتح من Safari مباشرة. من شاشة تسجيل الدخول بجهاز الوندوز اضغط "عرض رمز الدخول السريع من الهاتف" وامسح الرمز بكاميرا الآيفون (بشرط نفس شبكة الواي فاي). تكدر تضيفه للشاشة الرئيسية (Add to Home Screen) ليصير مثل تطبيق حقيقي.

## ملاحظات
- كل البيانات تُخزَّن بملف JSON على جهاز السيرفر (`server/data/auola-data.json` أو مجلد بيانات المستخدم بتطبيق الوندوز). خذ نسخة احتياطية بشكل دوري من صفحة الإعدادات.
- إذا انطفى جهاز السيرفر (الوندوز)، تتوقف بقية الأجهزة عن رؤية البيانات الجديدة لحين تشغيله مرة أخرى.
